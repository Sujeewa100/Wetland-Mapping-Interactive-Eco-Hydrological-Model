# Diyasaru Wetland Park - GIS & Remote Sensing Project

## Overview
This repository / folder contains GIS data, digitizing layers, spatial maps, and project documentation for the **Diyasaru Wetland Park** project.

---

## Directory Structure & Organization

```
Diyasaru_Park_GIS_Project/
│
├── 01_ArcGIS_Map_Documents/
│   └── Diyasaru digitized work(Completed).mxd   # Main ArcGIS Map Document
│
├── 02_Vector_Layers_Shapefiles/
│   # Place all digitized vector data here (.shp, .shx, .dbf, .prj, .cpg)
│   # e.g., Boundaries, Water bodies, Walkways, Vegetation zones, Infrastructure
│
├── 03_Raster_Imagery_and_Scans/
│   # Base satellite imagery, drone orthomosaics, scanned maps (.tif, .jpg, .ecw)
│
├── 04_Tabular_Data_and_Attributes/
│   # Attribute tables, biodiversity census data, water quality parameters (.xlsx, .csv)
│
├── 05_Documentation_and_Reports/
│   # Methodology reports, metadata, field study notes (.pdf, .docx)
│
└── 06_Exported_Maps_and_Graphics/
    # High-resolution map layouts ready for GitHub showcase and portfolio (.png, .pdf, .jpg)
```

---

## Instructions for GitHub Portfolio
1. Add high-resolution exported map layouts (.png / .jpg) in `06_Exported_Maps_and_Graphics` so viewers on GitHub can preview the maps immediately.
2. Ensure relative path storage is enabled in ArcMap (`File -> Map Document Properties -> Store relative pathnames to data sources`).
